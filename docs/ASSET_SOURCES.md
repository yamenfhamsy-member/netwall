# Asset sources

This project uses **ready-made system assets only**. No AI-generated or procedurally
generated textures, models, or sounds are used.

| File | Source | Author / License | Notes |
|---|---|---|---|
| `res/drawable/ic_shield.xml` | Hand-authored simple monochrome shield outline (UI chrome, not a texture) | Project, MIT | Flat vector, black/white only |
| `res/drawable/ic_notification.xml` | Hand-authored white shield outline | Project, MIT | Status-bar icon |
| App icons in lists | Android `PackageManager.getApplicationIcon()` (other apps' own icons) | Respective app owners | Displayed, never modified |
| Fonts | System default (renders Arabic via the OS) | — | No bundled font files |
| Sounds / 3D models | None | — | Not used in v1 |
